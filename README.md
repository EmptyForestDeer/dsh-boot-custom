# dsh-boot-custom

DSH **鲸鱼娘星云启动动画**：星云背景 + **Canvas 逐帧动画的 DeepSeek 品牌**（左侧）+ **拟人鲸鱼娘**（右侧）+ 启动进度可见 + 点击/Esc 放行 + **失败有兜底**，片尾鲸鱼娘说「欢迎回来」。

## 界面组成

| 元素 | 来源 | 说明 |
|---|---|---|
| 星云背景 | 内置 CSS/SVG | 多层径向渐变呼吸 + 8 颗漂移粒子 + 旋转星图网格 |
| **DeepSeek 品牌（左）** | **Canvas 逐帧绘制** | "DeepSeek" 渐变大字 + 一道光横扫；官方鲸鱼 logo 用流动虚线光逐段描边（`Path2D` + `setLineDash`） |
| **鲸鱼娘（右）** | **Canvas 逐帧绘制** | **拟人少女形象**（参考蓝发女仆装鲸鱼娘）：蓝色长发 + 呆毛 + 侧辫 + **鲸鳍耳** + 大蓝眼 + 深蓝裙白围裙 + 挥手。程序化动画：从右侧游入 → 呼吸浮动 → 眨眼（每 4.2s）→ 挥手 → 张嘴说话；**无任何素材文件、无气泡** |
| 「欢迎回来」 | Canvas 绘制 + **真人声** | 动画结束前 2.5s 弹出对话气泡（带小尾巴），随退场一起溶解；同一时刻用**真人声**轻声说出「欢迎回来」（素材随插件分发：`assets/audio/welcome.m4a`）。素材被浏览器自动播放策略挡住时保持安静，素材缺失时才回退系统语音 |
| **片尾品牌字卡（视频主题）** | **全屏暗晕 + Canvas** | 视频进入最后 3.8s 时淡入：一块全屏暗角 + 金属质感 "DeepSeek / HARNESS" 字卡 + 流动描边的鲸鱼 logo。**用来盖住素材自带的烧录水印**（详见「片尾水印处理」） |
| 底部 UI | 内置 | 标题 + 真实进度条 + 提示行 |

> 两侧都是 `requestAnimationFrame` 驱动的逐帧绘制，**不是 CSS 关键帧，也不引用任何插件立绘**。视频主题下素材一揭示首帧，品牌/鲸鱼娘 Canvas 即淡出（素材自带画面），仅片尾字卡会再出现。

## 机制（为什么能抢在内核前面）

DSH 内核的启动页由 shell 模块脚本同步构建。本插件在 Host 侧订阅内核官方的 `webserver/index-inject` 事件，往 `<head>` 注入**两行解析阻塞脚本**（一行配置全局、一行屏幕脚本），因此覆盖层在**内核 boot 页出现之前**就占住视口。入口 id / 路由 / 命名空间全部独立（`boot-custom`）。

三半结构：

| 半侧 | 文件 | 职责 |
|---|---|---|
| Host | `entry.js` | 素材/清单/优化路由 + `webserver/index-inject` 注入 + `Config`（schemastery，全 volatile） |
| 屏幕 | `src/boot-screen.js` | 纯脚本（非模块），星云动画 / 可选视频，观察内核 `--dsh-boot-arc` 进度，交接与兜底 |
| 客户端 | `src/client.js` → `lib/client.js` | ①`clientReady()` 无条件最先调用 ②设置卡片（`plugins.item` 槽） |

## 设置在哪里

**设置 → 插件 → 插件配置** → 「星云启动动画」：

| 项 | 作用 |
|---|---|
| 开启启动动画 | 总开关。关=完全不注入（0 行），回到原生 boot 页 |
| 动画主题 | **星云（内置）**：纯 CSS/SVG，零素材；**视频素材池**：播 mp4（随机或轮播），池空自动回退星云 |
| 淡入时长 | 1 / 1.5 / 2 / 3 / 4 秒 |
| 进入方式 | 片尾交叉溶解（默认）/ 放完再淡 / 点击才进 |
| 播放影片声音 | 仅视频主题有意义；关=彻底静音 |
| 片尾语音「欢迎回来」 | 开=结束时**真人声**说一句「欢迎回来」（跟随上面的声音开关）；关=只出气泡文字 |
| 点鼠标直接进入 | 第一下点击就进，不再先开声音 |
| 显示底部提示 | 只隐藏提示行 |
| 素材池 | **点「上传素材」直接传短片**（支持多选，单条 ≤200MB，无需碰文件夹）；勾选参与；逐条真实播放探时长；`未优化` 徽章 + 无损 `优化` 按钮 |
| 多条素材的选取方式 | **随机**（每次抽一条，尽量不连续重样）/ **轮播**（按顺序一条接一条，多窗口共用进度不撞车） |

改设置**刷新页面生效**（改了 `src/boot-screen.js` 也只需刷新——Host 每次渲染 index 都重读它；改了 `entry.js` 需重启 DSH，改了 `src/client.js` 需重跑 `build-client.mjs`）。

## 安装

方式一（推荐，走官方插件入口）：**设置 → 插件 → 添加插件** 指向本仓库。包内自带的 `cordis.patch.yml`（`bundle.patch`）会把 `- insert: id: boot-custom` 自动挂进 profile，无需手改任何配置文件。

方式二（本地开发/软链）：

1. profile 的 `package.json` → `dependencies` 加 `"dsh-boot-custom": "link:<本目录绝对路径>"`，并把 `dsh-boot-custom` 追加进 `dsh.profile.bundles`；
2. `pnpm install`（或确保 profile `node_modules/dsh-boot-custom` 能解析到本目录）；
3. 本目录内需能解析到 `@deepseek-ai/schemastery`（≥3.18.4，`.volatile()` 所在版本）——常规 pnpm 安装即可满足。

**重启 DSH 后生效。** 验证：重启后打开 DSH，看到开屏动画 + 标题 + 进度条 + 「播完自动进入 · 点一下提前进」即成功；若仍看到原生 boot 页，说明客户端模块图需要重启补齐（这是预期，重启一次即可）。

## 放视频（可选）

素材有两种进池方式，效果完全一样（Host 每次请求清单实时扫目录）：

1. **在设置卡片里点「上传素材」**（推荐）：支持一次多选，单条最大 200MB；同名不覆盖，自动改名 `xxx (2).mp4`；传完立即可用，还能当场点「预览」看效果。
2. **把 mp4 / webm 丢进 `assets/videos/`**：刷新设置页即入池。

素材规范：

| 项 | 建议 |
|---|---|
| **编码** | **必须 H.264（`libx264`）**。Chromium/Electron 不带 HEVC(H.265) 软解，Windows 的 HEVC 扩展只在部分机器上可用——**HEVC 素材在这里会黑屏不播**。手机/AI 站导出的 mp4 常是 HEVC，先转：`ffmpeg -i in.mp4 -c:v libx264 -crf 19 -pix_fmt yuv420p -c:a aac -movflags +faststart out.mp4` |
| 画幅 | 16:9（1280×720 即可） |
| 时长 | 8–15s（片长就是进入前的等待时间） |
| 容器 | `moov` 必须在文件最前（否则整段下完才出画面；卡片里有「优化」按钮可无损前移） |
| 轨道 | 带 AAC 音轨 |
| 构图 | 主体别顶满、四边留深色（蒙版会渐隐边缘） |
| 文字 | 尽量不出现文字/水印（自带的也没关系，见下） |

## 片尾水印处理

素材片尾若自带烧录字卡/水印（AI 生成站导出的短片很常见），视频主题会在最后 3.8s 淡入一层**全屏暗角 + 本插件自己的品牌字卡**（金属 "DeepSeek / HARNESS" + 流动描边鲸鱼 logo），把水印区盖成有意的品牌收尾，而不是留下修补痕迹。之所以用覆盖而不是像素修补（delogo）：水印区背景通常是光点/光弧/发丝这类复杂纹理，像素修补会留下明显条纹伪影。

> 覆盖层几何与不透明度由 `tools/verify-geometry.mjs` 断言：水印 bbox 四角处暗角不透明度 ≥ 0.95；时序由 `verify-timing.mjs` 断言：仅在片段最后 `CARD_LEAD_MS`（3.8s）内出现，且短于 ~6s 的片段自动跳过。换别的带片尾水印的素材时，若水印位置不同需同步调整 `.dshbc-card` 渐变中心与 `WM` 断言框。

## 素材池现状

`assets/videos/dsh-boot-whale.mp4` = 随仓库附带的演示素材（H.264/AAC/faststart，10.1s、1280×720、4.3MB）。默认主题即「视频素材池」；池空时自动回退星云。

## 交接与兜底（每条都有离线断言）

| 卡在哪 | 谁来放开 |
|---|---|
| 星云动画放完（`NEBULA_MS`=8s 计时） | 就绪即进（tail/end 模式） |
| 视频片段放完但内核未就绪 | 停最后一帧等 `clientReady` |
| 素材清单挂住 | 10 秒后按无素材处理，就绪即进 |
| 素材池空（视频主题） | 自动回退星云动画 |
| 某片段 6 秒无画面 | 换下一段；全失败就绪即进 |
| 片段时长未知 | 20 秒兜底 |
| 内核启动失败 | 琥珀色「启动失败，点击查看」 |
| 内核一直不就绪 | 15 秒「启动较慢，点击继续」 |
| 以上全部失效 | Esc / 空格 / 回车 随时直接进 |

## 自检（离线、零系统改动）

```bash
node tools/verify-all.mjs               # 静态 + 时序 + 几何 + 路由，全部离线
node tools/verify-install-rehearsal.mjs # 安装预演：依赖/bundles/链接/patch/导入/产物
```

覆盖：注入行在 shell 前、两半命名空间一致、Config volatile 与默认值、客户端产物契约、`ctx.get` 禁用手卫生、属性值引号、星云/视频/click 三种时序兜底、片尾字卡时序与暗角不透明度、语音三路径（真人声/被策略挡住静默/素材缺失回退）、轮播选取按序推进、上传路由四道闸门（GET 拒绝/穿越名/非视频扩展名/超体积上限）。

## 卸载

关掉「开启启动动画」并刷新页面 = 完全不注入，回到 DSH 原生启动页。彻底卸载 = 从 profile 的 `dependencies` 与 `dsh.profile.bundles` 中移除 `dsh-boot-custom`（含其 `node_modules` 链接），重启 DSH。
